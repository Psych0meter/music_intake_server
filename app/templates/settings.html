SongRec

Audio fingerprinting (Shazam-compatible) - free, unlimited, no key required.

Disabling this also stops Album from being filled in for most tracks. SongRec is currently the only detector whose album guess is reliable enough to be useful - AcoustID's album coverage is much weaker.

Genius / Whisper (lyrics fallback)

Local Whisper transcription + Genius lyrics search - only runs when SongRec and AcoustID both find nothing.

CPU-heavy when it actually runs (a real transcription pass, up to three 20-second clips per track) - though only on the genuine dead ends where SongRec and AcoustID both found nothing, never on every file. If you rely on it heavily on a large library, prefer more vCPUs over a very high Scan Workers value below.

Scan performance

How many files to identify concurrently. Picked up at the start of the next scan cycle - no restart needed.

0 = auto (min(8, CPU count)). Raise it if you have spare cores and a fast connection to your source; lower it if you're hitting AcoustID/iTunes/Genius rate limits.
